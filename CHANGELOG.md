- Edits in the desktop app show their added and removed line counts. The desktop doesn't send the edit's result, so the counts come from the edit itself.

## 0.1.0 - 2026-10-25

- First release. Narration, tool calls, grouped reads and searches, and slash-command output draw in a faint tinted italic, and Claude's answers keep their normal look.
- Each faded tool line has a details button that brings back the app's full card.
- Added and removed line counts stay green and red, and a failed call still says "failed" in red.
